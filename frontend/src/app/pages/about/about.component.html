Sobre esta aplicação

Esta aplicação foi desenvolvida para gerenciar contatos de forma eficiente, segura e intuitiva. No front-end, foi utilizado Angular com TypeScript e Bulma para entregar uma interface responsiva, rápida e moderna.

No back-end, a aplicação conta com a robustez do Node.js, Express, Prisma ORM e banco de dados PostgreSQL.

Com esta ferramenta, você pode cadastrar, editar, filtrar e exportar seus contatos para arquivo CSV com extrema facilidade.
